## Problem Statement

The **General Recommendation System** is a simple Python-based recommendation program that asks a student about their interests, preferred category and difficulty level. It then gives recommendations based on matching preferences.

This project uses basic Python concepts such as variables, input/output, lists, dictionaries, loops, conditions, functions and simple sorting.

## Scope of the Project

The project is designed as a small beginner-level recommendation system .
The current scope includes:
- Taking student interests as input.
- Taking a preferred technical category.
- Taking a preferred difficulty level.
- Comparing the preferences with stored course information.
- Giving a simple match score.
- Displaying courses from the highest match score to the lowest.
- Running the project using VS Code or the command line.


## Target Users

The main target users are:

- College students.
- Beginner programmers.
- Students exploring technical fields.
- Students who are unsure which beginner-friendly topics to learn next.

## High-Level Features

1. **Student Input**
   - Takes the student's name and preferences.
2. **Interest Matching**
   - Matches interests with course topics.
3. **Category Matching**
   - Checks the student's preferred technical category.
4. **Difficulty Matching**
   - Checks whether the student prefers Easy or Medium topics.
5. **Simple Recommendation Score**
   - Gives points when preferences match course information.
6. **Sorted Recommendations**
   - Displays the highest-scoring recommendations first.
