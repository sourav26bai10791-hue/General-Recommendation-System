# General Recommendation System

## Overview of the Project

The **General Recommendation System** is a simple Python-based recommendation program that asks a person about their interests, preferred category and difficulty level. It then gives recommendations based on matching preferences.

This project uses basic Python concepts such as variables, input/output, lists, dictionaries, loops, conditions, functions and simple sorting.

2. Python.org
3. GitHub
4. Google
## Steps to Install & Run the Project

### 1. Install Python
Download and install Python 3 from the official Python website.

### 2. Open the Project
Extract the 'VITyarthi Project' file.
Open the extracted project folder in **VS Code**.
The folder should contain:

data.py
display.py
input_helper.py
main.py
recommender.py
README.md
statement.md
### 3. Open the Terminal

In VS Code, open:
**Terminal → New Terminal**
Make sure the terminal is opened inside the project folder.

### 4. Run the Project
Use:

```bash
python main.py
```

If `python` does not work on Windows, try:

```bash
py main.py
```
